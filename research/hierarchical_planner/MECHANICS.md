## Verified integration fact
`Discrete(3111)` = WAIT + per-tile ADD/REMOVE for E/S edges + 2 `ChooseUpgrade` slots. `ActionKind` (`Entrypoint.cs:2469`) has no motorway / bridge / roundabout / traffic-light placement kind, `ApplyAction` (`Entrypoint.cs:2952`) dispatches only to road add, tile clear and upgrade selection. Motorways therefore exist in the planner only as **typed candidates with `feasibility='unsupported'`**; no executable motorway action is fabricated.

* Motorway placement semantics (ramp tiles, cost, `IsPermanent`), bridge count per water crossing, roundabout footprint, traffic-light cycle; vehicle routing algorithm and road capacity.
* Which upgrade each `ChooseUpgrade` slot represents (the observation carries only the pending count).
* Concrete top-up rule after decision 561.
