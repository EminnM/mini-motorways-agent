# S30 — Native midgame benchmark feasibility (decision memo; nothing launched)

## 1. Where legitimate midgame states come from
* **No stored snapshots are needed.** Native play under a deterministic policy is reproducible decision-for-decision (S22: 11/12 full episodes identical, S23/S27: base ≡ base2 on 29/29 forks; the only drift is a rare one-decision transient). A midgame state is therefore *constructible on demand* and legitimately: `RESET(seed)` + planner-B prefix for N decisions, which costs N/25 ≈ 6 s for N = 150 per episode on one instance. Every such state was reached by legal native actions (planner B: 0 illegal actions in 100+ episodes).
* **Snapshot restore** (DIAG_FORK) exists only in-memory within one request; a Python-side save/load op would be a small additive plugin change, but it is unnecessary for the benchmark above and its restore equivalence is validated **only for motorway-free states** (S22b 5/5; M2: fails with a motorway present). Motorways first become available at decision 421 (3/12 seeds), so midgame starts at 150–300 are motorway-free and need no restore at all.
* **Seed separation:** the state is a function of (seed, N), so train/eval split by seed is exact. Available seeds: 12 designated evaluation seeds (keep for evaluation), 24 S7 capture seeds and 10 S27 pilot seeds already used in research but not for training, and any new seed (e.g. 700000 + 7919·i) for training.

"Meaningful strategic choices" at these states, by the evidence: road topology (S23/S24/S25: none measurable), spawn placement (S27: not steerable), upgrade choice (M1: inert), motorway (M2: no eligible placement), REMOVE (never needed: concrete never binds). The remaining decisions are *which house to connect next and by which route* — exactly the S19 strategic action space, where a learned selector matched but did not beat random selection among planner candidates (synthetic) and planner B natively already connects 83–86 % of new houses within 60 decisions. Survival is decided by overcrowding of the single destination when a colour's destination has not spawned (3/12 seeds) and by per-destination demand/car supply (S26) — neither controllable by road actions found so far.

## 3. Fixed evaluation protocol (defined now; not run)
Evaluation seeds = the 12 designated seeds; start states = planner-B prefix to N ∈ {150, 250} (two benchmarks); the agent plays from there to 600; metrics: deliveries, survival decisions, new-house connection within 60, destroyed connections, illegal actions; baseline = planner B continuing from the same state (deterministic ⇒ exact pairing); random strategic choice as the lower reference; one episode per seed per start (deterministic baselines), stochastic agents with 3 sampling seeds; paired per-seed differences with the S13a caveat for stochastic policies (per-seed SD ≈ 55 deliveries) — decisive only for large effects, as in S21.

## 4. Throughput and budget
Measured: one headless instance runs 10–25 decisions/s including planner/adapter and logging (S13: 25/s; S21/S22 with heavier logging: 10/s); 4 parallel instances ≈ 40–80 decisions/s aggregate. A 150-decision prefix per episode adds ~6 s. For a strategic (candidate-level) policy one decision ≈ 5–10 primitive decisions. Budgets: 100k primitive decisions ≈ 25–40 min; 1M ≈ 4–7 h; a strategic policy at 50k strategic decisions ≈ 250–500k primitive ≈ 1–3 h. Compute is **not** the constraint.

## 5. Decision
**A for feasibility** — legitimate midgame states are available on demand (deterministic prefix replay), seed-separated, with restore validated for the motorway-free range, a fixed protocol and ample throughput. **No-go for starting native RL now on these states**, because the same evidence base shows no decision in this regime where any policy has beaten planner B on deliveries or survival: the benchmark would measure the agent's ability to re-learn connectivity, which the planner already provides for free. The honest precondition for native RL is a demonstrated headroom: a state family and action set where some non-planner policy achieves higher deliveries or survival. Two bounded ways to establish it without new mechanics research: (i) run the S19 hybrid (planner candidates + learned/random selector) *natively* from the N = 150 benchmark with the native reward on 12 held-out seeds — if random candidate choice already matches planner B natively as it did synthetically, close the primitive-topology objective; (ii) compare planner B against the human-like extreme of *doing nothing after full connectivity* (WAIT) from N = 150 — if survival and deliveries are identical, the midgame contains no decision at all in this regime and the project objective must move to longer/denser regimes (survive past week 3) where motorways, bridges and demand growth matter. Both are ≤ 15 min native and require no new code beyond the existing adapters.
